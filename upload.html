How to write the Word file

Type your questions in Word like this, then save as .docx (File > Save As > Word Document). Do not use the old .doc format.

1. Which device forwards packets between networks?
A. Hub
B. Switch
C. Router
D. Modem
Answer: C
Explanation: A router uses IP addresses to connect networks.

2. Which topology uses a central switch?
A. Bus
B. Star
C. Ring
D. Mesh
Answer: B
  • Each question has exactly 4 choices, A to D, one per line.
  • Number the questions (1. 2. 3. or Q1.) so they are easy to tell apart.
  • Show the correct answer in any one of these ways: an Answer: C line; an answer key at the end (Answer Key then 1. C, 2. B ...); making the correct choice bold, underlined, or highlighted; or putting * after it.
  • Explanation: is optional. Keep it in one paragraph.
  • If something cannot be understood, you will see a warning and can fix the answer in the preview before saving.
