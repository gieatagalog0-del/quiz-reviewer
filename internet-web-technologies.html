Subject overview

This subject covers how the Internet and the Web work and how to build web pages and web applications with HTML, CSS, and JavaScript, along with the protocols and security ideas behind them.

Internet fundamentals and the World Wide Web

The Internet is the global network of connected networks. The World Wide Web (WWW) is a service on the Internet made of linked pages and resources identified by URLs. It was invented by Tim Berners-Lee. Email and file transfer are other Internet services.

A URL has parts: https://www.example.com:443/path/page.html?id=5 includes the protocol, domain, port, path, and query string.

Web browsers, web servers, and client-server architecture

  • Web browser (client): requests resources and displays pages (Chrome, Firefox, Edge).
  • Web server: stores resources and responds to requests (Apache, Nginx, Tomcat).

Client-server architecture: the client sends a request and the server sends a response. A web app often has a front end (what runs in the browser), a back end (server logic), and a database.

Static vs. dynamic: a static page is sent as stored. A dynamic page is generated by server code (for example Java or PHP) for each request.

HTML structure and elements

HTML (HyperText Markup Language) defines the structure and meaning of content using elements made of tags and attributes.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My Page</title>
  </head>
  <body>
    <h1>Welcome</h1>
    <p>Hello, <a href="about.html">learn more</a>.</p>
    <img src="logo.png" alt="School logo">
  </body>
</html>
  • Headings: h1 (largest) to h6.
  • Common elements: p, a, img, ul, ol, li, table, form, input, button.
  • Semantic elements: header, nav, main, section, article, footer describe meaning, which helps accessibility and search engines.

CSS styling and layouts

CSS (Cascading Style Sheets) controls presentation: colors, fonts, spacing, and layout.

.card {
  background: white;
  padding: 1rem;
  border-radius: 12px;
}
#title { color: navy; }
h1 { font-size: 2rem; }
  • Selectors: element (h1), class (.card), id (#title).
  • Box model (inside to outside): content, padding, border, margin.
  • Flexbox: one-dimensional layout in a row or column (display: flex).
  • Grid: two-dimensional layout in rows and columns (display: grid).
  • Media queries: make pages responsive to different screen sizes.

JavaScript fundamentals

JavaScript adds behavior to web pages. It runs in the browser and can change the page (the DOM), react to events, and talk to servers.

const name = "Ana";          // cannot be reassigned
let score = 0;               // can change

function addPoint() {
  score++;
  document.getElementById("score").textContent = score;
}

document.getElementById("btn").addEventListener("click", addPoint);
Remember: HTML = structure, CSS = style, JavaScript = behavior.

HTTP and HTTPS

HTTP (HyperText Transfer Protocol) is the request-response protocol of the Web (default port 80). HTTPS is HTTP secured with TLS encryption (default port 443).

MethodUse
GETRetrieve data (parameters appear in the URL)
POSTSend data to the server (for example a form, sent in the request body)
PUT / DELETEUpdate / remove a resource
Status codeMeaning
200OK
301Moved permanently
403Forbidden
404Not found
500Internal server error

Domain names and DNS

People use names such as example.com, but computers use IP addresses. The Domain Name System (DNS) translates domain names into IP addresses.

  1. You type a domain name in the browser.
  2. Your computer asks a DNS resolver, which looks up the answer (using caches and DNS servers).
  3. The resolver returns the IP address.
  4. The browser connects to that IP address and requests the page.

Web application development and security fundamentals

  • Use HTTPS so data in transit is encrypted.
  • Validate input on the server, not only in the browser.
  • XSS (cross-site scripting): attackers inject scripts into pages. Prevent it by escaping output.
  • SQL injection: attackers change database queries through input. Prevent it with parameterized queries.
  • Passwords: never store them in plain text; store salted hashes.
  • Keep software updated to patch known vulnerabilities.
