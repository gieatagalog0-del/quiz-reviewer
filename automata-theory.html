Subject overview

Automata Theory studies simple abstract machines and the languages they can recognize. It is the foundation for compilers, text searching, and protocol design.

Basic terminology and formal languages

  • Alphabet (Σ): a finite, non-empty set of symbols. Example: Σ = {0, 1}.
  • String: a finite sequence of symbols from the alphabet. Example: 0110.
  • Length |w|: the number of symbols in w. |0110| = 4.
  • Empty string (ε): a string with no symbols. |ε| = 0.
  • Σ*: the set of all strings over Σ, including ε.
  • Language: any set of strings over an alphabet (a subset of Σ*).
Example: Over Σ = {0, 1}, the language L = {strings that end with 1} contains 1, 01, 11, 101, and so on.

Operations on languages: union (L1 ∪ L2), concatenation (L1L2), and Kleene star (L*, zero or more strings from L joined together).

Finite automata

A finite automaton is a machine with a finite number of states that reads an input string one symbol at a time and moves between states. If it ends in an accepting (final) state after reading the whole string, the string is accepted.

Deterministic Finite Automata (DFA)

A DFA is defined by a 5-tuple (Q, Σ, δ, q0, F):

  • Q: finite set of states
  • Σ: input alphabet
  • δ: transition function, δ: Q × Σ → Q
  • q0: start state
  • F: set of accepting states
Key rule: In a DFA, every state has exactly one transition for every input symbol.
Example: DFA for strings over {0,1} that end with 1. States: q0 (start), q1 (accepting). From either state, input 1 goes to q1 and input 0 goes to q0.

Nondeterministic Finite Automata (NFA)

An NFA is like a DFA but δ maps to a set of states, so a state may have several transitions (or none) for the same symbol. A string is accepted if at least one path leads to an accepting state.

Remember: NFAs are often smaller and easier to design, but they are no more powerful than DFAs. Both recognize exactly the regular languages.

Epsilon-NFA (ε-NFA)

An ε-NFA adds ε-transitions, moves that happen without consuming any input symbol. The ε-closure of a state is the set of states reachable from it using only ε-transitions (including itself). ε-NFAs make it easy to combine machines, which is why Thompson's construction uses them.

Regular expressions

A regular expression describes a language using a compact pattern.

PatternMeaningExample
aThe symbol aa
R1 | R2 (or R1 + R2)Union: R1 or R2a|b matches a or b
R1 R2Concatenation: R1 then R2ab matches ab
R*Kleene star: zero or more of Ra* matches ε, a, aa, ...
εThe empty string
Examples: 1(0|1)* means binary strings that start with 1. (a|b)*abb means strings over {a,b} that end with abb.

Thompson's construction

An algorithm that builds an ε-NFA from a regular expression by combining small pieces, each with one start state and one accepting state:

  • Single symbol a: start state, a-transition, accepting state.
  • Union (R1|R2): a new start state with ε-moves into both machines, and both end in a new accepting state through ε-moves.
  • Concatenation (R1R2): connect the accepting state of R1 to the start state of R2 with an ε-move.
  • Star (R*): add ε-moves that allow skipping the machine or repeating it.

DFA and NFA conversion

Every NFA has an equivalent DFA. The subset construction does the conversion:

  1. The DFA start state is the ε-closure of the NFA start state.
  2. For each DFA state (a set of NFA states) and each symbol, collect all NFA states reachable on that symbol, then take the ε-closure.
  3. Repeat until no new sets appear.
  4. Any DFA state containing an NFA accepting state is accepting.
Remember: An NFA with n states may need up to 2n DFA states in the worst case.

Transition diagrams and transition tables

A transition diagram draws states as circles, transitions as labeled arrows, the start state with an incoming arrow, and accepting states as double circles. A transition table shows the same information in rows and columns.

DFA for "ends with 1" as a table (→ marks the start state, * marks accepting):

StateOn 0On 1
→ q0q0q1
* q1q0q1

Trace of the string 101: q0 →(1) q1 →(0) q0 →(1) q1. It ends in the accepting state q1, so 101 is accepted.
