Subject overview

Networking explains how computers and devices connect and exchange data, from your home Wi-Fi to the Internet. You will learn the layouts, rules (protocols), addresses, and devices that make communication possible.

Fundamentals of computer networking

A network is a group of connected devices that share data and resources such as files, printers, and Internet access.

  • Node: any device on the network (computer, phone, printer).
  • Protocol: a set of rules for communication (HTTP, TCP, IP).
  • Bandwidth: how much data can be sent per second.
  • Client and server: a client requests a service and a server provides it.

Network topologies

A topology is the layout of how devices are connected.

TopologyDescriptionAdvantageDisadvantage
BusAll devices share one main cable.Cheap and simpleOne cable break can stop the whole network
StarAll devices connect to a central switch or hub.Easy to manage; one failed cable affects one deviceThe central device is a single point of failure
RingEach device connects to two neighbors in a loop.Orderly data flowA break can disrupt the ring
MeshDevices connect to many others.Very reliableExpensive and complex
HybridA combination of two or more topologies.FlexibleComplex design
Remember: Most modern LANs use a star topology with a switch.

Layered models split communication into smaller jobs so that each layer can focus on one task.

TCP/IP has four layers: Application, Transport, Internet, and Network Access (Link). It is the model the real Internet uses.

IP addresses and IP address classes

An IP address identifies a device on a network. IPv4 uses 32 bits written as four numbers from 0 to 255 (for example 192.168.1.10). IPv6 uses 128 bits.

ClassFirst octetDefault maskTypical use
A1 to 126255.0.0.0Very large networks
B128 to 191255.255.0.0Medium networks
C192 to 223255.255.255.0Small networks
D224 to 239n/aMulticast
E240 to 255n/aExperimental
  • Private ranges: 10.x.x.x, 172.16.x.x to 172.31.x.x, 192.168.x.x
  • Loopback: 127.0.0.1 points to your own computer.
  • Subnet mask: separates the network part from the host part.
  • Default gateway: the router that leads to other networks.

Network devices

DeviceWhat it does
HubRepeats incoming data to every port (Layer 1). Creates a lot of traffic.
SwitchLearns MAC addresses and sends data only to the correct port (Layer 2).
RouterConnects different networks and forwards packets using IP addresses (Layer 3).
Access pointLets wireless devices join a wired network.
ModemConverts signals so you can connect to your Internet provider.
Remember: Hub = shouts to everyone. Switch = talks to the right device. Router = connects networks.

LAN, MAN, and WAN

  • LAN (Local Area Network): a room, building, or campus. Example: a school computer lab.
  • MAN (Metropolitan Area Network): a city or large campus area.
  • WAN (Wide Area Network): a large geographic area. The Internet is the largest WAN.

Network communication and troubleshooting

When a connection fails, work from the bottom up: cables and power, then IP settings, then DNS and applications.

  • ping 127.0.0.1 tests your own network software.
  • ping the default gateway to test your local network.
  • ping 8.8.8.8 tests Internet connectivity. If this works but a website name fails, suspect DNS.
  • ipconfig (Windows) or ip a (Linux) shows your IP settings.
  • tracert (Windows) or traceroute (Linux) shows the path packets take.
