Subject overview

Object-Oriented Programming (OOP) organizes software around objects that combine data and behavior. It makes programs easier to reuse, extend, and maintain. Examples here use Java.

Four pillars of OOP: Encapsulation, Inheritance, Polymorphism, Abstraction.

Classes and objects

A class is a blueprint. An object is a real instance built from that blueprint. One class can create many objects.

public class Student {
    String name;
    int grade;
}

// Creating objects
Student s1 = new Student();
Student s2 = new Student();
Analogy: A house plan is the class. Each house built from the plan is an object.

Attributes and methods

  • Attributes (fields) hold the object's data or state.
  • Methods are actions the object can perform.
public class Student {
    String name;          // attribute
    int grade;            // attribute

    void displayInfo() {  // method
        System.out.println(name + ": " + grade);
    }
}

Constructors

A constructor is a special method that runs when an object is created. It has the same name as the class and no return type. If you write none, Java supplies a default no-argument constructor. The keyword this refers to the current object.

public class Student {
    private String name;
    private int grade;

    public Student(String name, int grade) {
        this.name = name;
        this.grade = grade;
    }
}

Student s = new Student("Ana", 90);
Remember: Several constructors with different parameters are allowed. This is constructor overloading.

Encapsulation

Encapsulation bundles data and methods together and hides the data from outside code. Make fields private and offer public getters and setters so the class can validate changes.

public class Account {
    private double balance;

    public double getBalance() { return balance; }

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
}
Benefit: The object protects its own data from invalid values.

Inheritance

Inheritance lets a class (subclass) reuse the attributes and methods of another class (superclass) using extends. Use super to refer to the parent.

class Animal {
    void eat() { System.out.println("Eating..."); }
}

class Dog extends Animal {
    void bark() { System.out.println("Woof!"); }
}

Dog d = new Dog();
d.eat();   // inherited
d.bark();
Remember: A Java class can extend only one class, but it can implement many interfaces.

Polymorphism

Polymorphism means "many forms": the same method call can behave differently depending on the object.

  • Overloading (compile time): same method name, different parameters, in one class.
  • Overriding (runtime): a subclass replaces a method it inherited, with the same signature.
class Animal { void sound() { System.out.println("Some sound"); } }
class Cat extends Animal {
    @Override
    void sound() { System.out.println("Meow"); }
}

Animal a = new Cat();
a.sound();   // prints Meow

Abstraction

Abstraction shows only what is necessary and hides the details. In Java you use abstract classes and interfaces.

  • An abstract class cannot be instantiated and may contain abstract methods without a body.
  • An interface is a contract of methods. A class uses implements to promise to provide them.
abstract class Shape {
    abstract double area();
}

class Circle extends Shape {
    double r;
    Circle(double r) { this.r = r; }
    double area() { return Math.PI * r * r; }
}
